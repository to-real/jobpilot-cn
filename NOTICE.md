This fork adds China-market job discovery features, including Boss Zhipin
scanning and a lightweight in-project browser access layer inspired by
eze-is/web-access:

  https://github.com/eze-is/web-access

The Web Access-inspired code in this fork is implemented directly in this
repository using the existing Playwright dependency; it does not require the
external Web Access skill at runtime.

career-ops maintainer or by Boss Zhipin.
